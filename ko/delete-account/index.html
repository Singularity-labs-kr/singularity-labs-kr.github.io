계정과 데이터 삭제

Singularity Labs 게임의 계정 삭제를 앱 안에서 시작하거나 이메일로 요청할 수 있습니다.

게임 안에서 삭제하기

  1. 인터넷에 연결한 뒤 로비의 설정 → 개인정보와 계정을 엽니다.
  2. 계정과 데이터 삭제를 누릅니다.
  3. 삭제되는 항목을 읽고 예를 누릅니다. 삭제한 진행 상황과 보유 재화는 복구할 수 없습니다.

삭제 실패 안내가 나오면 연결을 확인하고 같은 메뉴에서 다시 시도해 주십시오.

앱 없이 삭제 요청하기

sglrt77@gmail.com로 제목을 ‘계정 삭제 요청’으로 보내 주십시오. 플레이어 ID를 알고 계시면 함께 적어 주십시오. 게임 안에서는 설정 → 개인정보와 계정 → 플레이어 ID 복사에서 확인할 수 있습니다.

ID를 모르셔도 요청할 수 있습니다. 앱을 다시 설치하실 필요는 없습니다. 담당자가 삭제 대상과 요청 권한을 확인하고 처리 결과를 답장으로 안내합니다.

삭제하면 어떻게 되나요?

게임 진행, 보유 재화와 장비가 삭제 대상입니다. 서버가 게임 데이터 삭제를 확인하면 기기에 저장된 게임 진행도 지웁니다. 플레이 통계 삭제 요청이나 로그인 계정 삭제 절차가 남으면 해당 계정으로 다시 연결될 때 재시도합니다. 남은 처리 상태는 이메일로 문의하실 수 있습니다.

구매 거래 기록은 플레이어 ID와의 연결을 끊고 별도로 보관합니다. 기기에서 선택한 통계 전송 거부와 맞춤형 광고 거부는 유지됩니다.
