싱귤래리티 · 대한민국 Google Play 비공개 테스트

2026년 11월 28일 개정 · Android 1.0.4(빌드 11)의 게임 자료 업데이트 안내 추가

이 방침은 초대받은 이용자가 Android 비공개 테스트판을 설치하고 플레이할 때 적용됩니다. 빌드 10까지 게임은 오프라인으로 작동합니다.

빌드 11에서 게임 자료를 받을 때

첫 안내 전투를 마치고 앱을 다시 열면, 기기에서 연령과 지역별 동의 상태를 확인한 뒤 공식 사이트(playsingularitygames.com)에서 작은 버전 목록과 새 게임 자료를 받을 수 있습니다. 파일을 전달하는 웹 서버는 연결한 기기의 IP 주소를 받습니다. 이 요청에는 출생 연도, 광고·기기 식별자, 계정 정보, 게임 진행 기록이나 진단 자료를 담지 않습니다. 연령 미확인 또는 보호 대상 이용자는 요청을 건너뜁니다. 오프라인에서도 기기에 있는 자료로 플레이할 수 있습니다.

기기에 저장되는 정보

게임은 이어서 플레이할 수 있도록 진행 상황, 재화, 장비, 설정을 앱 전용 공간에 저장합니다. 연령 확인 화면에서 출생 연도를 입력하면 기기에 저장해 연령 확인에 사용합니다. 각 판의 스테이지, 시간, 결과, 무기 선택과 성능 정보도 플레이 기록으로 남습니다. 테스터 코드가 설정되어 있으면 해당 코드로 기록을 구분합니다. 운영자는 기기에 있는 이 기록에 접근할 수 없습니다. 이 버전은 온라인 게임 계정, 운영 광고, 실제 구매와 서버 저장을 사용하지 않습니다.

기록을 지우거나 옮길 때

Android 설정에서 앱 → 도망은 둥글게 → 저장공간 → 데이터 삭제를 선택하면 해당 기기의 진행 상황과 플레이 기록이 삭제됩니다. 기기 제조사에 따라 메뉴 이름은 조금 다를 수 있습니다. 게임 안에서 진행만 초기화하면 플레이 기록 파일은 남을 수 있습니다.

Android 시스템 백업이나 기기 이전을 사용하면 운영체제가 진행 저장 파일과 그 예비 사본을 백업하거나 새 기기로 옮길 수 있습니다. 게임이 지정한 백업·이전 대상에서는 플레이 기록을 제외했습니다. 기기에서 앱 데이터를 지운 뒤에도 기존 시스템 백업은 남을 수 있습니다. 해당 백업은 기기와 Google 계정의 백업 설정에서 관리할 수 있습니다. Android 백업 안내

스토어와 외부 페이지

Google Play가 Google 계정으로 설치 자격을 확인하고 앱을 배포합니다. Google Play에서 비공개 의견을 직접 제출하면 개발자가 해당 의견을 볼 수 있습니다. 운영자가 초대할 이용자의 이메일을 Google Play 명단에 등록하는 경우 그 주소는 초대 관리에 사용됩니다. 운영자가 관리하는 초대 명단과 테스트 의견은 테스트 종료 후 90일 이내에 삭제합니다. Google 개인정보처리방침

게임에서 안내 페이지를 열면 외부 브라우저가 실행됩니다. 사이트를 제공하는 GitHub Pages는 보안을 위해 방문자의 IP 주소를 기록합니다. 페이지를 열 때 게임 진행 파일이나 플레이 기록이 함께 전달되지는 않습니다. GitHub Pages 개인정보 안내

개인정보 문의

싱귤래리티 게임 지원은 게임에 관한 개인정보 문의와 열람·정정·삭제·처리정지 요청을 받습니다. 지원 이메일을 직접 보내시면 운영자는 회신 주소와 작성하신 내용, 선택해 첨부하신 자료를 Gmail에서 받습니다. 일반 문의는 처리 완료 후 1년간 보관하고, 테스트 의견은 테스트 종료 후 90일 이내에 삭제합니다. 플레이 기록 파일은 자동으로 첨부되지 않습니다. 지원 문의를 보내지 않고도 게임을 플레이할 수 있습니다. 기기에만 남는 기록은 위의 Android 설정에서 직접 삭제할 수 있습니다. 공식 지원 안내
