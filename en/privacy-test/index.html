Never Run Straight Privacy Policy

Singularity · Google Play closed test in South Korea

Updated November 28, 2026 to cover game content downloads in Android 1.0.4 (build 11).

This policy applies when invited testers install and play the Android closed test. Builds up to and including build 10 run offline.

Game content downloads in build 11

When you reopen the game after the introductory battle, it checks your age eligibility and regional consent status on your device. Eligible installations may request a small version list and updated game content from the official website (playsingularitygames.com). The web server receives your IP address to deliver the files. The request does not include your birth year, advertising or device identifiers, account details, game progress, or diagnostic records. The game skips the request when your age is unknown or you are in a protected age group. You can play offline with the content on your device.

What stays on your device

The game saves progress, currency, equipment and settings in its app storage so you can resume playing. If you enter a birth year on the age-check screen, the game keeps it on your device for the age check. It also writes a playtest log with details such as the stage, duration, result, weapons selected and performance. If a tester code is set, it groups logs by that code. The operator cannot access these on-device logs. This version does not use online game accounts, live ads, real purchases or server-side saves.

Deleting or moving your data

In Android settings, choose Apps → Never Run Straight → Storage → Clear data to erase progress and playtest logs on that device. Menu names can vary by device. Resetting progress inside the game can leave playtest log files on the device.

If you use Android system backup or device transfer, Android may back up or move the progress save file and its backup copy. The game's rules exclude playtest logs from system backup and device transfer. An existing system backup may remain after you clear the app's local data. You can manage system backups in your device and Google Account backup settings. Android backup help

The store and external pages

Google Play uses your Google Account to check eligibility and distribute the app. If you submit private feedback directly through Google Play, the developer can see that feedback. When the operator adds a tester's email address to a Google Play invitation list, that address is used to manage participation. The operator deletes the invitation lists and test feedback it manages within 90 days after the test ends. Google Privacy Policy

Links to information pages open in your external browser. GitHub Pages, which hosts those pages, logs visitors' IP addresses for security. Opening a page does not send your game save or playtest logs to the site. About GitHub Pages data collection

Privacy questions

Singularity game support handles privacy questions and requests to access, correct, delete or restrict the processing of information. If you choose to email support, the operator receives your reply address, message and any attachments you select in Gmail. The operator keeps general inquiries for one year after resolving them and deletes test feedback within 90 days after the test ends. Playtest logs are not attached automatically. You can play without emailing support. You can delete on-device records yourself using the Android settings described above. Official support
